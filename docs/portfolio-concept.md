## Demo project
Use this only as demo placeholder project content for now.

Project Name: Black Tidemark
Project Type / Genre: Third-person stealth-action level design case study
Engine / Software Used: Unreal Engine 5, Blueprints, Blender, Miro, Photoshop
Project Duration: 9 weeks
Team Size: Solo project
Role: Level Designer

One-line Summary:
A storm-battered coastal relay station where the player must infiltrate the fortress, restore the signal beacon, and escape before the lower docks are flooded.

Project Goal:
To create a tense but readable level that showcases landmark-based navigation, layered stealth routes, and a strong vertical finale.

Target Player Experience:
The player should feel cautious at first, then increasingly confident as the level opens into multiple routes, clearer sightlines, and more deliberate choices.

Design Pillars:
1. Landmark-Driven Navigation
2. Layered Stealth and Traversal Routes
3. Fail-Forward Progression

Gameplay Beats:
1. Cliffside arrival and first stealth read
2. Service tunnel infiltration and power reroute
3. Courtyard multi-route encounter
4. Beacon tower ascent and escape sequence

Key Mechanics:
1. Patrol-based stealth navigation
2. Climb / vault / traversal pathing
3. Simple power-routing puzzle interaction

Challenges:
1. Middle section was initially too large and slowed pacing
2. Alternate route was not clearly readable in early tests

Iterations / Improvements:
1. Compressed the courtyard and tightened travel time between encounters
2. Added a stronger visual beacon landmark, better cover placement, and clearer side-route framing

Final Outcome:
A 12–15 minute vertical-slice level focused on stealth, readable exploration, and cinematic progression.

What Was Learned:
The project improved understanding of pacing, sightline control, spatial readability, and how iteration feedback can strengthen player guidance.
