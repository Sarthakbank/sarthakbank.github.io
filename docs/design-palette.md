# Design Palette — Approved Source

## Brand direction
Premium, clean, modern, recruiter-friendly, cinematic, and polished.
Support both dark mode and light mode.

## Dark theme
Primary colors:
- Deep Black — #000000
- Dark Grey — #1C1C1E
- Soft Graphite — #2C2C2E

Text colors:
- Pure White — #FFFFFF
- Soft Grey — #A1A1A6

Accent colors:
- Electric Blue — #0A84FF
- Neon Orange — #FF9F0A
- Mint Green — #30D158

## Light theme
Primary colors:
- Pure White — #FFFFFF
- Deep Charcoal — #1D1D1F
- Soft Grey 1 — #F5F5F7
- Soft Grey 2 — #D2D2D7

Text colors:
- Mid Grey Text — #6E6E73

Accent colors:
- Blue Accent — #0071E3
- Muted Orange — #FF9500
- Teal Accent — #30B0C7

## Usage guidance
- Build both dark and light mode from the start
- Keep the palette premium and restrained
- Use blue as the main interactive accent by default
- Use orange for iteration/challenge emphasis
- Use mint/teal for success/outcome emphasis
- Avoid noisy multi-color components
- Keep section backgrounds neutral and typography strong

## Style reminders
- rich spacing
- strong headings
- premium cards/panels
- subtle borders
- elegant contrast
- media-first project presentation
- modern but not flashy
